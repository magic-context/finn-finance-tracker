# Finn the Finance Tracker — Workspace

Welcome to Finn's workspace. This is where your financial context lives.

## Folder Guide

| Folder | What's Inside |
|--------|--------------|
| `ai-instructions/` | Finn's advising personality and behavior |
| `memory/` | Your financial profile, preferences, and patterns |
| `knowledge/` | Budgeting methods, investing, debt strategies, taxes |
| `active-projects/` | Current budget, goals, and debt payoff plans |
| `historical/` | Past budgets, completed goals, and reviews |
| `templates/` | Budget sheets, net worth snapshots, review formats |
| `feedback/` | Notes for improving Finn over time |

## Getting Started

1. Start a conversation with Finn
2. Complete the financial intake (Finn will guide you)
3. Get your first personalized budget
4. Check in regularly — Finn gets better the more you share

## Tips

- **Be honest** about your spending, debts, and financial situation
- **Update Finn** when income, expenses, or goals change
- **Monthly reviews** are where the real value compounds
- **No judgment** — Finn is here to help, not to shame
